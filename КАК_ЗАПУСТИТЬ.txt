========================================
  КАК ЗАПУСТИТЬ АЛИСУ (Windows)
========================================

1. Убедись, что в папке есть файлы:
   - bot.py
   - personality.py
   - memory.py
   - .env
   - memory.json (создастся сам при первом запуске)

2. Открой командную строку (или PowerShell) в этой папке.

3. Установи зависимости (один раз):

   pip install aiogram python-dotenv groq

4. Запусти бота:

   python bot.py

5. Если увидел сообщение «Алиса запускается...» —
   всё работает. Окно не закрывай — бот работает, пока оно открыто.

6. Остановка: нажми Ctrl+C в окне командной строки.

========================================
  КАК ПЕРЕДАТЬ ДЕВУШКЕ
========================================

1. Найди своего бота в Telegram (через @BotFather или поиск по username).
2. Отправь ей ссылку на бота или просто перешли контакт бота.
3. Она нажимает «Запустить» / пишет /start.
4. Дальше можно просто переписываться.

Важно:
- Бот должен быть запущен на твоём компьютере (или сервере), пока она с ним общается.
- Если выключишь компьютер / закроешь окно — бот перестанет отвечать.
- История сохраняется в файле memory.json и не теряется между запусками.

========================================
  КОМАНДЫ
========================================

/start  — приветствие
/help   — список возможностей
/reset  — забыть текущий диалог

В группе бот отвечает, если:
- её позвать по имени «Алиса»
- ответить на её сообщение
- упомянуть через @username
